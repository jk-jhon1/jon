🐛 TROUBLESHOOTING:

❌ Erro: "CORS" ou "Cannot access audio"
   ✓ Solução: Certifique-se de usar http://localhost (não file://)

❌ Áudio não toca
   ✓ Abra: http://localhost:8000/teste-audio.html
   ✓ Se o teste funcionar, clique em qualquer lugar do jogo
   ✓ Abra console (F12) para ver mensagens de debug

❌ Servidor não inicia
   ✓ Verifique se port 8000 está disponível
   ✓ Tente outro: python3 -m http.server 9000
   ✓ Acesse: http://localhost:9000

❌ Arquivo não encontrado (404)
   ✓ Certifique-se de que floresta.mp3 está na pasta raiz
   ✓ Reinicie o servidor
