COMBATE SEMIREALISTA 3D - Setup Inicial

🎵 Áudio de Fundo Integrado!

Este jogo inclui som de floresta atmosférico que toca continuamente. Para que funcione corretamente, siga as instruções abaixo:

✨ Novidades do Jogo

🎵 Áudio de Floresta

Som de ambiente contínuo durante toda a partida

🎮 Controles Melhorados

Sistema de áudio integrado com inventário

⚡ Performance Otimizada

Carregamento automático de áudio com fallback

🔊 Volume Balanceado

40% de volume para não abafar sons do jogo

🚀 RÁPIDO (1 minuto)

Se estiver no Windows com Python instalado:

  1. Localize start-server.bat
  2. Clique duplo para abrir
  3. Acesse http://localhost:8000
  4. Aproveite o jogo!
✅ Forma mais fácil para Windows

⚙️ MANUAL (2 minutos)

Se preferir usar o terminal/prompt:

python3 -m http.server 8000

Depois abra no navegador:

http://localhost:8000
✅ Funciona em qualquer sistema

🧪 Testar Áudio Antes de Jogar

Para verificar se o áudio está funcionando corretamente:

  1. Inicie o servidor (veja instruções acima)
  2. Acesse: http://localhost:8000/teste-audio.html
  3. Clique em "REPRODUZIR" e escute o áudio
  4. Se funcionou, está pronto para jogar!
💡 Se o teste funcionar, o jogo também funcionará
